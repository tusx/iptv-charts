Custom command

Optional. When "Custom command" is selected this is run instead of a detected player — on the host, with your privileges, exactly as written. {% if bridged %} The bridge cannot check it from inside the container, so a typo shows up when you press play. {% endif %}

Placeholders: {url} the stream address, {title}, {user_agent}, {referrer}. The URL is appended at the end if the command never mentions it, and a flag whose placeholder has no value is left out altogether. Nothing is passed through a shell, so quotes only group arguments.

Metadata providers

TMDB supplies movie and series search, posters and overviews. Use the API Read Access Token from TMDB's API settings, not the older 32-character v3 API key. TVDB is optional: when a key is present it supplies episode names, numbers and air dates; without it, TMDB episode data is used instead. Tokens are stored in the app database, included in backups, and never displayed again.

Downloads and probing

    

      Every candidate is inspected with ffprobe before it is downloaded. The
      playlist's own connection limit is enforced across probes, syncs and
      downloads; a season therefore downloads one episode at a time when the
      limit is 1. Downloads for different playlists may run in parallel.

Library scan

  

    Find files already in the media folders, match them to TMDB entries, and
    review the matches before importing them. A scan also detects files that
    have gone missing from disk.
  

  Open library scan





  
Backup and restore

  

    The ZIP contains playlists, credentials, metadata tokens, the movie/series
    libraries, quality profiles, queue and history — but not the IPTV catalog,
    which is rebuilt by a sync. Keep the file private: it contains
    secrets in plain text.
  

  

    
    
  

  

  
Restoring replaces the current library, settings and playlists.
