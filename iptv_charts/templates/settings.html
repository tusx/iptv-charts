Settings

Metadata providers, refresh schedule, quality profiles, library scan and backup. Player settings live on Playlists; naming and search defaults live on the Movies and Series settings pages. Global fields save together with the button at the bottom.

Metadata providers

TMDB supplies movie and series search, posters and overviews. Use the API Read Access Token from TMDB's API settings, not the older 32-character v3 API key. TVDB is optional: when a key is present it supplies episode names, numbers and air dates; without it, TMDB episode data is used instead. Tokens are stored in the app database, included in backups, and never displayed again.

Refresh schedule

Metadata is refreshed on a schedule so new releases, posters and episode data appear without a manual refresh. Playlists can be refreshed before searches so new VODs are found; set playlist refresh to 0 to disable it. Movie and series search intervals are on their section pages.

{{ icon('sliders') }} Quality profiles

A profile decides which resolutions and sources are acceptable, what audio and subtitles are required, and when upgrades stop. Movies and series choose one when they are added. You have {{ profile_count }} profile{{ '' if profile_count == 1 else 's' }}.

{{ icon('magnifying-glass') }} Library scan

Find files already in the media folders, match them to TMDB entries, and review the matches before importing them. A scan also detects files that have gone missing from disk.

Open library scan

{{ icon('box-archive') }} Backup and restore

The ZIP contains playlists, credentials, metadata tokens, the movie/series libraries, quality profiles, queue and history — but not the IPTV catalog, which is rebuilt by a sync. Keep the file private: it contains secrets in plain text.

Restoring replaces the current library, settings and playlists.
